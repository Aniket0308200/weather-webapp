┌─ STEP 1: PREREQUISITES ─────────────────────────────────────────────────────┐
│                                                                             │
│  ✓ Python 3.8+          → Download from python.org                        │
│  ✓ Ollama               → Download from ollama.ai                         │
│  ✓ OpenWeatherMap Key   → Get free key from openweathermap.org/api        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 2: FIRST TIME SETUP (DO ONCE) ────────────────────────────────────────┐
│                                                                             │
│  1. Get API Key:                                                           │
│     → https://openweathermap.org/api                                      │
│     → Sign up (free)                                                       │
│     → Copy API key                                                         │
│                                                                             │
│  2. Setup .env file:                                                       │
│     → cd my-weather-app/backend                                           │
│     → copy .env.example .env (Windows)                                    │
│     → cp .env.example .env (macOS/Linux)                                  │
│                                                                             │
│  3. Edit .env:                                                             │
│     → Open .env in text editor                                            │
│     → Replace 'your_api_key_here' with your actual key                    │
│     → Save                                                                 │
│                                                                             │
│  4. Install Ollama:                                                        │
│     → Download from ollama.ai                                             │
│     → Install                                                              │
│     → Run: ollama pull deepseek-r1:1.5b                                   │
│     → Wait for download (~1GB)                                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ STEP 3: RUNNING (EVERY TIME) ──────────────────────────────────────────────┐
│                                                                             │
│  You need 3 TERMINALS open at the same time:                              │
│                                                                             │
│  ┌─ TERMINAL 1: OLLAMA ────────────────────────────────────────────────┐  │
│  │                                                                     │  │
│  │  $ ollama serve                                                     │  │
│  │                                                                     │  │
│  │  Expected: Listening on 127.0.0.1:11434                           │  │
│  │  Status: ✓ KEEP RUNNING                                           │  │
│  │                                                                     │  │
│  └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌─ TERMINAL 2: BACKEND ───────────────────────────────────────────────┐  │
│  │                                                                     │  │
│  │  Windows:                                                           │  │
│  │  $ cd my-weather-app\backend                                       │  │
│  │  $ run_backend.bat                                                 │  │
│  │                                                                     │  │
│  │  macOS/Linux:                                                       │  │
│  │  $ cd my-weather-app/backend                                       │  │
│  │  $ chmod +x run_backend.sh                                         │  │
│  │  $ ./run_backend.sh                                                │  │
│  │                                                                     │  │
│  │  Expected: Running on http://127.0.0.1:5000                       │  │
│  │  Status: ✓ KEEP RUNNING                                           │  │
│  │                                                                     │  │
│  └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│  ┌─ TERMINAL 3: FRONTEND ──────────────────────────────────────────────┐  │
│  │                                                                     │  │
│  │  $ cd my-weather-app                                               │  │
│  │  $ npm run dev                                                      │  │
│  │                                                                     │  │
│  │  Expected: Local: http://localhost:5173/                          │  │
│  │  Status: ✓ KEEP RUNNING                                           │  │
│  │                                                                     │  │
│  └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │

║                         TROUBLESHOOTING                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

Problem: "Cannot connect to Ollama"
Solution: Make sure Terminal 1 is running "ollama serve"

Problem: "Port 5000 already in use"
Solution: Close other apps or restart computer

Problem: "Module not found"
Solution: Run "pip install -r requirements.txt" in Terminal 2

Problem: "API key error"
Solution: Check .env file has correct API key

Problem: Chat not responding
Solution: Check all 3 terminals are running
